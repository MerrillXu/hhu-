# 使用教程

> 30 秒看完流程，5 分钟跑起来。

---

## 📦 第一步：准备 exe

下载 `release/hhu抢课v1.03正式版.by-MerrillXu.exe` 到任意目录，**双击运行**。

⚠️ Windows SmartScreen 可能弹出警告：
```
Windows 已保护你的电脑
Microsoft Defender SmartScreen 阻止了无法识别的应用...
```
点击 **`更多信息`** → **`仍要运行`** 即可。

---

## 🎯 第二步：填课程规则（问答式）

启动后脚本会用问答方式让你填配置，每条规则包括 5 项：

```
[第 1 问] 选课类型？
  [1] Public
  [2] Specialty
  [3] Any

[第 2 问] 课程名称关键词（如 "大学英语|高数" 用 | 分隔多个）

[第 3 问] 教师姓名（留空 = 不限）

[第 4 问] 排除词（留空 = 不限）

[第 5 问] 优先级（数字小=先抢，默认 5）
```

**示例**：抢"大学英语 / 王老师 / 排除实验班 / 优先级 3"
```
类型: 1 (Public)
关键词: 大学英语
教师: 王
排除: 实验
优先级: 3
```

填完一条后会问"要继续添加下一条吗？(y/n)"——输入 `y` 继续加，`n` 结束。

最多 8 条规则。

---

## ⚡ 第四步：填抢课参数

```
[轮询间隔秒数]  默认 1.0（多久拉一次课程列表）
[提交间隔秒数]  默认 0.5（每个 worker 提交一次抢课的间隔）
[最大并发 worker 数]  默认 6
```

- 普通选手：默认够用
- 热门课/卷王：轮询 0.5s / 提交 0.3s / 12 并发
- 怕风控：轮询 2.0s / 提交 1.0s / 3 并发

---

## ⏰ 第五步：什么时候开始抢？

| 输入 | 含义 |
|---|---|
| 直接回车 | 立即开始 |
| `12:30:00` | 今天 12:30:00（已过则明天） |
| `明天12:30:00` | 明天 12:30:00 |
| `60` | 60 秒后开始 |

---

## 🔐 第六步：登录

输入**学号**和**教务密码**（输入不显示，直接粘贴也可以）。

脚本会自动：
1. 访问 CAS 登录页 → 提取 salt/execution/happyVoyage
2. 用 AES-128-CBC 加密密码
3. 提交登录 → 拿到 `bzb_jsxsd` cookie

---

## 🔍 第七步：zbid 探测

脚本会自动扫描 9 种 zbid 来源：
1. xsxk_index 302 重定向
2. 21 个候选 API 端点
3. main.htmlx 引用的 JS
4. xsMain_new.htmlx 引用的 JS
5. xklc_list 页面（含特殊参数变体）
6. xklc_view 页面
7. `<a href="?jx0502zbid=...">` 链接

**如果探测到 1 个** → 直接确认用  
**如果探测到多个** → 让你选  
**如果全部失败** → 强制手动输入（**不允许 Enter 默认沿用**），想沿用本地必须输 `s`

---

## 🚀 第八步：开抢

进入抢课循环后：
- 第一轮会拉课程池 → 匹配 → 启动 worker
- 每个 worker 在后台不停提交抢课请求
- 抢到 / 放弃 / 已满 → worker 自动结束
- **所有命中已派发 + 所有 worker 结束** → 自动退出

---

## 🛑 中断

按 **`Ctrl+C`** 任何时候可以中断退出。

---

## 💡 小贴士

1. **挂机**：开抢前 60 秒脚本才会登录，session 不会过期
2. **复跑**：zbid 自动保存到 `~/hhu_config.json`，下次会优先用本地缓存（除非过期）
3. **调试**：脚本所有输出都在当前终端窗口，不写日志文件
