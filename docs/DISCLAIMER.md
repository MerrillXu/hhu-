# 学术使用声明

## 用途

本工具（HHU 抢课工具）是一个**学习 / 研究性质**的 Python 脚本，旨在研究：
- 强智教务系统协议
- CAS 单点登录流程
- Python 网络编程（requests / AES 加密 / Cookie 管理）
- PyInstaller 打包

---

## 限制

1. **仅供学习交流使用**
2. **不得用于任何商业用途**
3. **不得用于干扰教务系统正常运行**
4. **不得用于绕过学校正常选课规则**

---

## 风险

使用本工具可能带来的风险包括但不限于：

- 🚫 **账号被封禁**：教务系统检测到异常请求可能封禁账号
- 🚫 **IP 被拉黑**：高频请求可能触发 IP 限流
- 🚫 **选课违规**：学校规定禁止使用第三方工具选课，违者可能受纪律处分
- 🚫 **成绩作废**：极端情况下已选课程可能被取消
