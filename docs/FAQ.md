# 常见问题排查

## 安装与运行

### Q：双击 exe 弹出"Windows 已保护你的电脑"
**A**：正常。点"更多信息" → "仍要运行"。这是因为 exe 没有数字签名。

### Q：双击 exe 后窗口闪退
**A**：
1. 在 PowerShell / cmd 里运行 exe，错误会保留
2. 检查 Python 依赖（`requests`、`pycryptodome`）

### Q：ModuleNotFoundError: No module named 'Crypto'
**A**：缺少 pycryptodome。装：`pip install pycryptodome`

### Q：requests.exceptions.ConnectTimeout
**A**：校园网问题。检查：
- 是不是连上了校园网 / 宽带
- 校园网 IPv6 不稳定 → 脚本已强制 IPv4
- 试试 `ping authserver.hhu.edu.cn`

## 登录

### Q：登录失败"用户名或密码错误"
**A**：
1. 先去浏览器手动登录 https://authserver.hhu.edu.cn 确认密码正确
2. 5 分钟后再试（CAS 风控，密码错 5 次会锁）
3. 密码里有特殊字符 → 确认密码输入框粘贴完整

### Q：登录失败"触发验证码"
**A**：被 CAS 风控了。换时间、换 IP / 热点

### Q：登录失败"提取 salt/execution 失败"
**A**：教务系统升级了，登录页面结构变了。等更新 / 或者去 https://github.com/MerrillXu/hhu- 提 issue

### Q：登录后 session 很快失效
**A**：长时间挂机会触发 session 过期。脚本会在开抢前 60 秒才登录，应该不会。但如果你**多次中途操作**，session 可能提前过期，建议直接挂着别动。

## zbid

### Q：脚本提示"未开放"但选课实际上已开始？
**A**：99% 是 **zbid 不匹配**（用到了上一轮的过期 id）。重新运行脚本让它自动探测新 zbid。

### Q：自动探测不到 zbid
**A**：
1. 等选课正式开始前 30 分钟再探测（提前太早页面可能还没更新）
2. 检查 zbid 来源：浏览器登录 → 学生选课中心 → 进入选课 → 地址栏 `?jx0502zbid=` 后面 32 位
3. 强制手动输入（脚本会要求）

### Q：探测到多个 zbid
**A**：选课系统里有多个轮次（正选 / 补退选 / 重修选课），选最相关的那个。一般补退选期间只有一个。

### Q：zbid 沿用本地失败
**A**：脚本不再允许直接回车默认沿用。想沿用必须输 `s`。这是为了防止用过期的 zbid。

## 抢课

### Q：脚本提示"已满"但名额还有
**A**：课程池数据有延迟。可能有人刚退课，刷新就能看到。

### Q：脚本提示"时间冲突"
**A**：你已选了同时段的另一门课。脚本会跳过这个冲突，自动尝试其他时段。

### Q：脚本提示"未开放"
**A**：选课时间没到 / 已经结束 / 课程类别不对（你选的是公共课，但这门是专业课）。

### Q：脚本提示"跨专业"或"非推荐"
**A**：教务系统不允许你选这门课（不在你培养方案里）。这条规则会被自动放弃。

### Q：一直没命中任何课程
**A**：
1. 检查关键词拼写
2. 检查教师姓名（"王老师" vs "王" vs "Wang"）
3. 改 "类型" 为"全部"试试
4. 排除词里是不是把目标词也排了？

## 打包（自己改源码后）

### Q：怎么改源码？
**A**：用 VS Code / Sublime 打开 `src/hhu_sniper_pro.py`，改完跑 `python src/hhu_sniper_pro.py` 调试。

### Q：怎么重新打包 exe？
**A**：
```bash
pip install pyinstaller
pyinstaller build/build.spec
# 产物在 dist/hhu抢课v1.03正式版.by-MerrillXu.exe
```

### Q：打包后 exe 找不到模块
**A**：在 `build.spec` 里加 `hiddenimports=['xxx']`。常见缺失：`Crypto`、`urllib3.util.connection`

## 其他

### Q：会被教务系统封号吗？
**A**：理论上高频请求可能触发风控（验证码 / IP 限流）。脚本设计为最多 16 并发、单次请求 < 1 秒，相对温和。**任何后果自负**。

### Q：账号密码会被泄露吗？
**A**：脚本纯本地运行，密码只在内存中用一次，**不写文件、不上传任何第三方**。源文件公开可审计。

### Q：能改成 GUI（图形界面）吗？
**A**：目前是纯命令行版本。GUI 改造方向已记录，但暂未实现。
